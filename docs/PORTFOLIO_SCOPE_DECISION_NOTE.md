# Portfolio Scope Decision Note

As of 2026-08-08, strict single-XAUUSD scope is no longer a hard requirement. A multi-asset or multi-commodity portfolio is acceptable if independent evidence and bounded validation indicate a materially better commercial opportunity.

This does **not** reopen broad search. The operating rule is:

`mechanism + external prior + pre-registered formulation + bounded test + explicit stop rule`

The present package expands scope only to XAUUSD/XAGUSD relative value. Any later diversified commodity basket requires a separate managerial go/no-go decision.
