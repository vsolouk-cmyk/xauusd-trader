# XAUUSD Macro Causal Panel V1

Builds a canonical, causal daily macro panel for XAUUSD research. It downloads only the missing GVZCLS series, selects exact-schema existing files for broad USD, real/nominal yields, breakeven, VIX, CFTC, official events, ETF and WGC data, and keeps forward targets in a separate file.

No paper, demo, MT5, broker, or live execution path exists.
