# Stage35B — Strict Variant Backtest / Queue Evaluator

## Purpose

Stage35B evaluates the targeted variants generated by Stage35A and separates them into:

- strict review-ready variants,
- pending forward-confirmation variants,
- acceleration-only variants,
- diagnostic-only variants,
- kill/repair variants.

It exists to prevent passive waiting while also preventing premature promotion to EA, paper-live, or order execution.

- `data/reports/stage35a_targeted_variant_generator/targeted_variant_specs.csv`
- `data/reports/stage32c_dense_forward_shadow_tracker/dense_forward_signal_ledger.csv`
- `data/reports/stage33e_short_confirmation_recency_filter/stage33e_summary.json`

## Execution

```bash
python3 -m app.stage35b_strict_variant_backtest_queue_evaluator
```

## Safety

This stage is research-only:

- no EA change,
- no paper-live,
- no order authorization,
- no commercial transition.

A passing Stage35B only permits the next research design step. It does not authorize execution.
