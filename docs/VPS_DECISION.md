# VPS Decision

## Current decision

Do not buy or operationalize a VPS yet.

## Reason

The project is still in Stage 0/1:

1. API key and provider access.
2. Data collection.
3. Data quality.
4. Baseline lab.

A VPS is not useful until MT5 validation or paper-order.

## Later VPS criteria

When the project reaches MT5 validation/paper-order, choose VPS based on:

- uptime,
- broker-server latency,
- Windows support if MT5 terminal is needed,
- remote desktop reliability,
- restart policy,
- logging/backup access.

## Practical rule

GitHub Actions is enough for REST/cloud collection now. VPS is a later execution-infrastructure decision.
