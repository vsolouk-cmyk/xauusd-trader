Data and code availability

The frozen registry, evaluation protocol, source hashes, normalized specification-level outcomes, derived tables, figure-building code, and independent audit artifacts are supplied with the replication package. The project repository is hosted at https://github.com/vsolouk-cmyk/xauusd-trader; the immutable repository snapshot referenced in this article is commit 0c24c7a47b36642e675a4de1b2f5829a40195666. Raw broker and vendor files are not redistributed because their licensing and access conditions may restrict public release. The manuscript reports the immutable SHA-256 bindings needed to verify author-held source files. A qualified researcher may request assistance in reconstructing the permitted inputs, but access to third-party data remains governed by the original providers.
