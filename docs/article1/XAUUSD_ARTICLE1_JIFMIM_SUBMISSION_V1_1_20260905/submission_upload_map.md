# Editorial Manager upload map

Use the final, rebuilt files only after inserting the repository URL/commit and confirming the remaining declarations in `author_metadata.tex`.

| Editorial Manager item | File | Required action |
|---|---|---|
| Manuscript | `manuscript.pdf` | Use for a non-anonymized workflow |
| Manuscript (anonymous) | `manuscript_anonymized.pdf` | Use if the journal requests blinded review |
| Title page | `title_page.pdf` | Upload separately in a blinded workflow |
| Highlights | `highlights.txt` | Five bullets, each within Elsevier's 85-character limit |
| Supplementary material | `supplementary_material.pdf` | Standalone readable supplement |
| Research data / supplementary data | `supplementary_data.zip` | Derived tables, protocol, and audit records; no restricted raw vendor files |
| LaTeX source files | `JIFMIM_ARTICLE1_LATEX_SOURCE_FLAT.zip` | Flat archive with TeX, BibTeX, class/style, tables, and figures |
| Cover letter | `cover_letter.pdf` | Journal-specific one-page letter |
| Declaration of interest | `declaration_of_interest.txt` | Confirm before upload |
| AI declaration | `ai_use_declaration.txt` | Also embedded in the manuscript |
| Data availability statement | `data_code_availability.txt` | Insert final repository URL and commit |

Do not upload both named and anonymous manuscripts as the same item. Follow the item labels displayed by the live system. Choose the subscription publication route to avoid the optional open-access APC.
