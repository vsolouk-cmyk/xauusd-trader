# Editorial Manager upload map

Use only the final rebuilt files. JIFMIM follows double-anonymized review, so the anonymized manuscript is the initial-review file.

| Editorial Manager item | File | Required action |
|---|---|---|
| Manuscript | `manuscript_anonymized.pdf` | Primary article file for initial double-anonymized review |
| Title page | `title_page.pdf` | Upload separately under the title-page item |
| Highlights | `highlights.txt` | Five bullets, each within Elsevier's 85-character limit |
| Supplementary material | `supplementary_material.pdf` | Standalone readable supplement |
| Research data / supplementary data | `supplementary_data.zip` | Derived tables, protocol, and audit records; no restricted raw vendor files |
| LaTeX source files, blinded | `JIFMIM_ARTICLE1_LATEX_SOURCE_ANONYMIZED_FLAT.zip` | Use if editable source is required during blinded review; identity scan passed |
| LaTeX source files, named | `JIFMIM_ARTICLE1_LATEX_SOURCE_FLAT.zip` | Retain for author archive or later production request; do not upload as a blinded-review item |
| Cover letter | `cover_letter.pdf` | Journal-specific one-page letter |
| Declaration of interest | `declaration_of_interest.txt` | Confirm before upload |
| AI declaration | `ai_use_declaration.txt` | Also embedded in the manuscript |
| Data availability statement | `data_code_availability.txt` | Repository URL is complete; long commit identifiers remain in package metadata rather than the article narrative |

Do not upload the named manuscript or named source archive as the initial blinded-review manuscript. Follow the exact item labels displayed by the live system. Choose the subscription publication route to avoid the optional open-access APC.
