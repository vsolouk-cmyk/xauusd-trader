# Article 2 Journal Fit V1

## Provisional decision

**Primary target: SoftwareX**, conditional on publishing a citable, installable software release with an explicit open-source license, stable repository URL, archived release DOI, minimal example, and author/AI disclosures. Its research-software scope fits a paper whose central contribution is an implemented architecture with executable evidence.

**Fallback: Journal of Open Source Software (JOSS)** only if the submission is intentionally shortened to the JOSS paper format and the repository meets its public open-development, documentation, testing, licensing, and research-impact criteria. JOSS is not a fallback for a closed repository.

## Why the manuscript stays journal-neutral now

The empirical evidence is frozen, but the public release identity and archival DOI are not. Formatting directly into a journal template before those items exist would create the appearance of submission readiness without satisfying the software-availability contract. The current draft therefore freezes claims and evidence first.

## Submission blockers

| Blocker | Required evidence | Status |
| --- | --- | --- |
| Public software identity | Stable public repository URL | OPEN |
| License | OSI-compatible license matching bundled dependencies | OPEN |
| Archived release | Version tag plus Zenodo or equivalent DOI | OPEN |
| Installation proof | Fresh-environment commands and captured output | PARTIAL |
| Minimal example | One bounded example independent of private market data | OPEN |
| External replication | Second pipeline or clearly scoped limitation | OPEN but not mandatory for initial software paper |
| Author metadata | Names, ORCIDs, affiliations, contributions | OPEN |
| Journal declarations | Funding, conflicts, data/software availability, AI use | OPEN |

## Re-check immediately before submission

Journal policies, templates, fees, and AI-disclosure language can change. Re-open the official current author guide, then adapt this evidence-bound draft without changing frozen results.
