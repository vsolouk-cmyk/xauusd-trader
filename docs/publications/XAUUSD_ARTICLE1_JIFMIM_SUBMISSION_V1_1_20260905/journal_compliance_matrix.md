# JIFMIM submission compliance matrix

| Requirement | Package implementation | Status |
|---|---|---|
| Elsevier CAS LaTeX source | `cas-sc` version 2.4 from the author-supplied template | Complete |
| Author-year references | `cas-model2-names.bst` and `natbib` | Complete |
| Editable LaTeX source | Flat source files with no subdirectories | Complete |
| Full manuscript PDF | `manuscript.pdf` | Complete after build |
| Anonymized review PDF | `manuscript_anonymized.pdf` | Complete after build |
| Separate title page | `title_page.pdf` and source | Author identity and affiliation complete; repository/declaration confirmation pending |
| Highlights | Five editable bullets in `highlights.txt`; each below 85 characters | Complete |
| Abstract and keywords | Structured CAS front matter | Complete |
| Figures | Vector PDF plus PNG previews; generated from frozen CSV data | Complete |
| Supplementary material | Standalone source/PDF plus machine-readable tables | Complete |
| Competing-interest declaration | Separate editable file and manuscript section | Author confirmation required |
| Funding statement | Title page and manuscript section | Author confirmation required |
| AI-use declaration | Separate file and manuscript section following Elsevier's disclosure structure | Complete; author review required |
| CRediT statement | Full and title-page versions | Author confirmation required |
| Data/code availability | Manuscript and separate editable file | GitHub URL/commit required |
| Cover letter | Journal-specific editable source/PDF | Author metadata complete; declarations require confirmation |
| Raw data redistribution | Excluded; immutable hashes retained | Confirm provider terms |
| Graphical abstract | Not supplied; no scientific need identified | Optional unless submission system says otherwise |
| Publication route | Subscription route selected; no APC | Confirm selection in Editorial Manager |

The public ScienceDirect guide page could not be programmatically retrieved in this environment. Compliance is based on the author-supplied official CAS 2.4 template, current official Elsevier LaTeX instructions, current Elsevier AI policy, and standard editable submission components. The corresponding author must compare the final upload fields with the live journal guide.
