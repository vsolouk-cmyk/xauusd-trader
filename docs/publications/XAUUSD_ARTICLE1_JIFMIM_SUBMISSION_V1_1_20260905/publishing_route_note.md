# Publishing route decision

Target journal: *Journal of International Financial Markets, Institutions and Money*.

Selected route: subscription publication. Elsevier states that authors publishing in hybrid journals can use the subscription model at no cost. The journal separately advertises an optional open-access APC of USD 3,590 excluding taxes. This package assumes that the optional open-access route will not be selected.
