# JIFMIM submission compliance matrix

| Requirement | Package implementation | Status |
|---|---|---|
| Elsevier CAS LaTeX source | `cas-sc` version 2.4 from the author-supplied template | Complete |
| Author-year references | `cas-model2-names.bst` and `natbib` | Complete |
| Editable LaTeX source | Flat source files with no subdirectories | Complete |
| Full manuscript PDF | `manuscript.pdf` | Complete; author archive/production file |
| Anonymized review PDF | `manuscript_anonymized.pdf` | Complete; primary double-anonymized review file |
| Separate title page | `title_page.pdf` and source | Complete |
| Highlights | Five editable bullets in `highlights.txt`; each below 85 characters | Complete |
| Abstract and keywords | Structured CAS front matter | Complete |
| Figures | Vector PDF plus PNG previews; generated from frozen CSV data | Complete |
| Supplementary material | Standalone source/PDF plus machine-readable tables | Complete |
| Competing-interest declaration | Separate editable file and manuscript section | Complete; none reported |
| Funding statement | Title page and manuscript section | Complete; no specific funding reported |
| AI-use declaration | Separate file and manuscript section following Elsevier's disclosure structure | Complete; code development is excluded from this declaration |
| Research-method AI disclosure | Brief statement in Methods, separate from the manuscript-preparation declaration | Complete under Elsevier's current code-development policy |
| CRediT statement | Full and title-page versions | Complete; final portal attestation remains the author's action |
| Data/code availability | Manuscript and separate editable file | Complete; repository URL supplied |
| Cover letter | Journal-specific editable source/PDF | Complete |
| Raw data redistribution | Excluded; immutable identifiers retained in the frozen manifest | Confirm provider terms in the portal if asked |
| Graphical abstract | Not supplied; no scientific need identified | Optional unless submission system says otherwise |
| Publication route | Subscription route selected; no APC | Confirm selection in Editorial Manager |

The current JIFMIM guide identifies a double-anonymized review process. Compliance also uses the author-supplied official CAS 2.4 template, current official Elsevier LaTeX instructions, and the current Elsevier AI policy. The corresponding author should still compare the upload labels with the live Editorial Manager fields because platform fields can change.

Official checks used on 2026-09-06:

- JIFMIM Guide for Authors: https://www.sciencedirect.com/journal/journal-of-international-financial-markets-institutions-and-money/publish/guide-for-authors
- Elsevier LaTeX instructions: https://www.elsevier.com/researcher/author/policies-and-guidelines/latex-instructions
- Elsevier generative-AI policy: https://www.elsevier.com/about/policies-and-standards/generative-ai-policies-for-journals
